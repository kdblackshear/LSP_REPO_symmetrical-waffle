Since Book.java only contains information regarding itself, it is not dependent on Library.java. The Library.java file acts as a coordinator that takes on the task of collecting the books and delegating mutations to them. A three book borrowing limit is enforced by Library.java, instead of Book.java, because Book.java is independent and doesn't have access to the inventory system wide. All of this is in regards to the Information Expert principle, in which only Library.java has global context to be able to track all of the active loans. Designing the system in this way separates the high level system rule from the individual object states.
